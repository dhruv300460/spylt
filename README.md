# Awwwards Site of the Day — Clone

A front-end clone of an [Awwwards](https://www.awwwards.com/) "Site of the Day" winner, built to recreate its animations, layout, and overall interactive feel using modern web technologies.

## Tech Stack

- ⚛️ React 19
- 🌀 Tailwind CSS v4
- 🎞️ GSAP (GreenSock Animation Platform)

## Features

- Parallax scrolling effects
- Clip-path based reveal animations
- ScrollTrigger & ScrollSmoother powered interactions
- Pinned sections with animated transitions
- Text reveal animations
- Smooth GSAP timelines throughout
- Fully responsive, mobile-friendly layout

## Getting Started

```bash
# 1. Install dependencies
npm install

# 2. Start the dev server
npm run dev

# 3. Build for production
npm run build

# 4. Preview the production build locally
npm run preview
```

## Project Structure

- `/public/videos` — video assets
- `/public/fonts` — custom fonts
- `/public/images` — image assets
- `/src` — application source code
